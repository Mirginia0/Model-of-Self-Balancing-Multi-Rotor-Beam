# Project media

## Folder structure

- `images/`: the photograph, diagrams, connection schematics and six result plots displayed in the main README.
- `photos/`: six additional still images associated with test recordings in the thesis presentation. These are kept separately from the result plots.
- `videos/`: MP4 test recordings. The reference-angle PI recording is a compressed H.264/AAC copy of the supplied file, without trimming. The other recordings preserve the supplied files.

Links provide direct access to the MP4 files. Depending on the browser, files may play or download. Large files may not preview on GitHub's file page.

The supplied file `Change P (1of2).MP4` is the P experiment, and `Change P (2of2).MP4` is the PI experiment, as confirmed by Martyna Rydczak. Their repository filenames reflect the controller used rather than the original misleading part labels.
